# Features

## 1. User Authentication

Users can securely access the platform using authentication.

### Features

* User registration
* User login
* User logout
* Password recovery
* User profile
* Protected routes
* Session management
* Role-based access

---

## 2. Workspace Management

A workspace represents a company, organization, or team.

### Features

* Create workspace
* Update workspace
* Workspace settings
* Workspace members
* Workspace roles
* Invite members
* Remove members

### Roles

```text
ADMIN
MEMBER
```

---

## 3. Project Management

Projects organize related tasks.

### Features

* Create project
* Update project
* Delete project
* Project description
* Project deadline
* Project status
* Project members
* Project progress

### Project Status

```text
PLANNING
IN_PROGRESS
COMPLETED

```

## 6. Dashboard

The dashboard provides a quick overview of work.

### Dashboard Statistics

* Total projects
* Total tasks
* Completed tasks
* Pending tasks
* Overdue tasks
* Tasks due today
* Tasks assigned to the current user

### Project Overview

```text

```

### Features

* User management

## 8. Notifications

Users receive notifications about important events.

### Notification Events

* Task assigned
* Task completed
* Task deadline approaching
* Project invitation
* Member added to project
* Important project updates

### Notification Types

```text
IN_APP
EMAIL
```

---

## 9. Activity Tracking

The system records important user activities.

Examples:

```text
John created a project
Sarah created a task
Alex assigned a task to John
John changed task status
Sarah completed a task
```

Activity tracking helps administrators understand what is happening inside the workspace.
